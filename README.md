# نظام الخطة التعليمية السنوية

تطبيق ويب لإدارة الخطط التعليمية السنوية للمعلمين، بديل عن ملف الاكسل الحالي، مع قسم تعلم فردي، مراجعة من المركز المسؤول، وتقارير للإدارة. الاستضافة محلية داخل المدرسة.

## محتوى المستودع

```
design/       - مستند التصميم الكامل: مخطط قاعدة البيانات، الأدوار، شاشات الواجهة
database/     - سكربتات PostgreSQL الجاهزة للتنصيب (schema.sql + seed.sql) ودليل التنصيب
prototypes/   - نماذج HTML تفاعلية لكل شاشة (تُفتح مباشرة بأي متصفح، بدون تنصيب)
```

## حالة المشروع

- [x] تصميم قاعدة البيانات والواجهات
- [x] نماذج تجريبية لكل الشاشات الأربعة (المعلم، المركز المسؤول، الإدارة، إدارة القوائم)
- [x] سكربتات تنصيب قاعدة البيانات
- [ ] التنفيذ الفعلي للتطبيق (Backend + Frontend)
- [ ] النشر على السيرفر المحلي
